# SmileSchool Website

![SmileSchool](https://i.imgur.com/placeholder.png)

## Description

This project is a fully styled web page for **SmileSchool** — a platform where you can learn to smile from the pros! Built using only HTML and CSS, this project implements a pixel-perfect design based on a Figma file.

## Features

- Responsive header with navigation
- Hero banner with background image
- Testimonial/quotes section
- Video tutorials listing with ratings
- Free membership section
- FAQ section
- Footer with social media links

## Technologies Used

- HTML5
- CSS3
- No external libraries or frameworks

## Pages

- `index.html` — Main page
- `styles.css` — All styles

## Design

The design was provided via Figma. Key design details:
- Font: Source Sans Pro
- Primary color: `#C271FF` (purple)
- Dark background: `#071629`
- Fully centered containers with max-width of 1000px
