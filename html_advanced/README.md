# HTML, Advanced — SmileSchool

![SmileSchool](https://upload.wikimedia.org/wikipedia/commons/thumb/6/61/HTML5_logo_and_wordmark.svg/120px-HTML5_logo_and_wordmark.svg.png)

## Description
This project builds a webpage from a Figma designer file using pure HTML only — no CSS, no styling.
The page is for SmileSchool, a platform teaching smile tutorials from professional instructors.

## Sections
1. Header — Logo + 3 navigation links
2. Banner — Hero section + 4 instructor blocks
3. Quote — Testimonial block
4. Videos — Most popular tutorials (4 video cards)
5. Membership — Free membership section
6. FAQ — 2 rows of 2 questions each
7. Footer — Logo + social links + copyright

## Requirements
- Pure HTML only
- No external libraries
- W3C compliant
